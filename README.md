# Pedro Villa Navarro

Final-year student in the **Dual Degree in Mathematics and Computer Engineering** at Universidad de Murcia (with an academic exchange year at **NTNU**, Trondheim). 

My interests sit at the intersection of formal mathematics—particularly topology, geometry, and mathematical modeling—and software engineering. I enjoy building systems from the ground up to understand their internal mechanics, ranging from low-level C engines and NumPy-based neural networks to full-stack web architectures and real-time multiplayer games.

---

### Featured Projects

* **[Lights](https://github.com/pedro-villa/Lights)** — *C99, SDL2, CMake, Make*  
  2D stealth and survival game built from scratch without a commercial game engine. Features a custom 2D raycasting and computational geometry module for real-time visibility polygons, AABB collision detection, opaque ADTs with manual memory management, and automated unit and simulation test suites.

* **[AI_Notebook](https://github.com/pedro-villa/AI_Notebook)** — *React 18, Vite, Node.js, Express, MongoDB, Jest/Vitest*  
  Full-stack web platform designed to track, declare, and audit the transparent use of AI in academic coursework. Implements JWT role-based access control (`student` and `admin`), interactive analytics dashboards, Docker support, and requirement traceability documentation.

* **[HandwrittenDigitRecognition](https://github.com/pedro-villa/HandwrittenDigitRecognition)** — *Python, NumPy, Tkinter*  
  Feedforward neural network (`[784, 16, 16, 10]`) implemented from first principles using only NumPy for matrix operations. Includes custom analytical backpropagation, mini-batch gradient descent, ReLU/Softmax activations trained on MNIST, and an interactive Tkinter drawing canvas for live inference.

* **[TDT4240-game (Loot'em Shoot'em)](https://github.com/pedro-villa/TDT4240-game)** — *Java 17, Kotlin, LibGDX, WebSockets, Android*  
  Cross-platform (Desktop & Android) real-time multiplayer top-down shooter developed for the Software Architecture course at NTNU. Built around a 20 Hz authoritative server loop communicating with thin clients via shared DTOs over WebSockets. *(Collaborative fork)*

* **[topologia-de-superficies](https://github.com/pedro-villa/topologia-de-superficies)** — *LaTeX, TikZ, BibLaTeX, GitHub Actions*  
  Collaborative mathematical lecture notes covering surface topology, compact surfaces, Euler characteristic, triangulations, homotopy, and the fundamental group, featuring a CI workflow for automated PDF compilation.

* **[chessAI](https://github.com/pedro-villa/chessAI)** — *Python, python-chess, Tkinter*  
  Modular chess sandbox decoupling board state validation (`BoardAdapter`), graphical interface, and engine decision-making to serve as a testbed for search and heuristic algorithms.
